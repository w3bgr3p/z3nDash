# Настройка сервера

## 1. Открыть Config

При отсутствии рабочей конфигурации DevDeck сам открывает страницу [[Config]].

## 2. Настроить базу

Выберите один режим:

- `PostgreSQL` — укажите полный connection string;
- `SQLite` — укажите путь к файлу базы.

Пример PostgreSQL:

```text
Host=127.0.0.1;Port=5432;Database=postgres;Username=postgres;Password=secret;Search Path=devdeck;Ssl Mode=Disable
```

`Search Path` определяет схему. DevDeck не требует схему `public`.

## 3. Настроить HTTP-сервер и логи

Укажите dashboard port и каталоги логов/отчётов, если значения по умолчанию не подходят.

## 4. Настроить OmniRoute

Укажите URL OmniRoute. При сохранении DevDeck проверяет `/v1/models` и показывает результат уведомлением.

## 5. Сохранить

После сохранения конфигурация перечитывается, а подключение к базе обновляется без ручного редактирования отдельных полей PostgreSQL.

## 6. Дополнительные данные

Config позволяет импортировать только:

- proxy;
- EVM addresses;
- SOL addresses.

Активные модули подготавливают свои таблицы автоматически.
