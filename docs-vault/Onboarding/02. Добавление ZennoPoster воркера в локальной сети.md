# Добавление ZennoPoster воркера

## Что требуется

На машине с ZennoPoster должен работать node-сервис, который отдаёт состояние и принимает команды по HTTP.

z3nDash хранит для узла:

- `machine`;
- `host`;
- `port`;
- время последнего обновления.

## Регистрация

Запись узла находится в таблице `zp_nodes` текущей схемы PostgreSQL или SQLite-базы.

`host` и `port` используются для запросов:

```text
GET  http://HOST:PORT/state
POST http://HOST:PORT/command
GET  http://HOST:PORT/log
GET  http://HOST:PORT/traffic
```

Логи и трафик узел отдаёт из файлов на своей машине; z3nDash их не хранит,
а пробрасывает запрос через `GET /zp/log` и `GET /zp/traffic`.
См. [[Logs]] и [[Traffic]].

## Проверка

1. Откройте [[ZP7]].
2. Убедитесь, что узел появляется в списке.
3. Проверьте загрузку состояния.
4. Отправьте команду запуска или остановки.
5. Откройте `allLogs` и `traffic` — узел должен отвечать в обоих окнах.

## Версия z3n7 на узле

Окно `traffic` запрашивает хвост файла параметром `tail`. Узел со старой сборкой
`z3n7.dll` этот параметр игнорирует и отдаёт **первые** N записей вместо последних —
данные будут, но не те. Раскатайте сборку с поддержкой `tail`.
