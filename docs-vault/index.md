# DevDeck

DevDeck — локальная Windows-панель для расписаний, ZennoPoster-узлов, логов, HTTP-трафика и вспомогательных инструментов.

## Запуск

1. Приложение загружает `appsettings.secrets.json`.
2. Если база настроена, DevDeck подключается к ней и открывает Scheduler.
3. Если конфигурации нет, открывается Config.
4. Встроенный HTTP-сервер по умолчанию слушает порт `10993`.

## Хранилище

DevDeck поддерживает:

- PostgreSQL через единый connection string;
- SQLite через путь к файлу.

Для PostgreSQL схема берётся из `Search Path` connection string. Таблицы, которые нужны активным обработчикам, создаются автоматически.

## AI

AI-запросы выполняются через OmniRoute. Адрес задаётся в [[Config]].
