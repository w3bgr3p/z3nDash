# Clips

Clips хранит именованные текстовые шаблоны для быстрого копирования.

## Возможности

- просмотр дерева шаблонов;
- выбор и копирование содержимого;
- создание и редактирование;
- сохранение пути, заголовка и текста.

## Хранилище

Данные находятся в таблице `clips`.

## API

- `GET /clips`
- `POST /clips`
