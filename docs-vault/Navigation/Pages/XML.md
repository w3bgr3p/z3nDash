# XML

Страница `/xml.html` открывает произвольный XML как дерево.

## Ввод

XML можно вставить в редактор, перетащить на страницу или выбрать через системный
диалог. Кодировка файла определяется по BOM, включая UTF-16 шаблонов ZennoPoster.
Кнопка **Format** форматирует исходный текст, **Parse** перестраивает дерево.

## Дерево

- поиск фильтрует теги, атрибуты и текст;
- уровни 1, 2, 3 и 5 позволяют быстро выбрать глубину раскрытия;
- отдельные узлы и всё дерево можно раскрывать и сворачивать;
- виртуальная прокрутка не создаёт DOM-элемент для каждой строки большого файла;
- ширина исходного текста и дерева меняется перетаскиванием разделителя и
  сохраняется локально.

Страница доступна из dock как **XML** и по `Alt+9`.
