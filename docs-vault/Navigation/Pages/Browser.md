# Browser

Browser управляет профилями антидетект-браузера. Переключатель в заголовке
выбирает, с каким браузером работать: **ZennoBrowser** или **ShardX**. Выбор
запоминается в браузере.

## Подключение

Адрес и токен берутся из раздела Browsers API на странице [[Config]]:

| Браузер | Настройка | Адрес по умолчанию | Авторизация |
|---|---|---|---|
| ZennoBrowser | `BrowsersApi.ZennoBrowser` | `http://localhost:8160` | заголовок `Api-Token` |
| ShardX | `BrowsersApi.ShardX` | `http://127.0.0.1:40325` | `Authorization: Bearer <token>` |

Токен на страницу не попадает: его подставляет сервер z3nDash при проксировании.

## Profiles

Таблица профилей: имя, папка, прокси, теги (только ZennoBrowser), статус,
время последнего запуска. У запущенного профиля вместо времени — PID и аптайм.

- **＋ New profile** — создать профиль: имя, платформа, папка, прокси, теги.
  ZennoBrowser: Auto (ОС хоста), Windows 10 или Windows 11. ShardX: Windows,
  macOS или Linux; новый отпечаток берётся из `/fingerprint/new/{platform}`.
  В ShardX папку можно задать новой строкой. Служебные папки ZennoBrowser
  «без папки» в форме не показываются, облачные помечены `(cloud)`.
- **✎ в колонке Proxy** — сменить прокси профиля: выбрать сохранённый, ввести
  новый строкой или снять.
- **Start / Stop** — запуск и остановка через API браузера.
- **Kill** — завершение процесса по PID в обход API.
- **WS** — копировать CDP-эндпоинт запущенного профиля. ShardX отдаёт его
  только для профилей, запущенных через API.
- **Stop All** — остановить все запущенные профили.

Фильтры: поиск по имени, прокси и тегам, папка, только запущенные.

## Proxies

Список сохранённых прокси. ZennoBrowser: имя, URI, статус проверки, время
проверки. ShardX: имя, `kind://host:port`, страна, id.

## Threads

Только ZennoBrowser: занятые потоки, освобождение по одному и все сразу.

## Особенности ShardX

Проверено на ShardX Launcher 2.0.3:

- время приходит в виде `@<unix-секунды>`, а не ISO;
- после `stop` профиль ещё около 7 секунд числится в `/running`, поэтому
  страница перечитывает список, пока он не пропадёт (не дольше 15 секунд);
- новый прокси строкой ShardX проверяет около 10 секунд, но привязывает
  даже нерабочий;
- удалённые профили попадают в корзину лаунчера.

## Особенности ZennoBrowser

- новый прокси строкой ищется среди сохранённых по точному URI; если такого
  нет, создаётся с именем `host:port`;
- смена прокси идёт через `update_proxy_bulk` — он меняет только прокси;
- профиль без папки ZennoBrowser кладёт локально в «Profiles without folder».

## API

- `/zb/api/*` — proxy в ZennoBrowser API;
- `/shardx/api/*` — proxy в ShardX Launcher API;
- `GET /zb/process/uptime?pids=...` — аптайм процессов по PID;
- `POST /zb/process/kill` — завершение дерева процессов по PID.
