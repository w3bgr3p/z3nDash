# Logs

Страница Logs показывает записи, принятые endpoint `/log` и сохранённые в каталоге логов.

## Возможности

- загрузка текущих записей;
- обновление через SSE;
- фильтрация по уровню, источнику и тексту;
- просмотр полной записи;
- очистка всех записей;
- очистка записей конкретной задачи.

## API

- `POST /log` — принять запись;
- `GET /logs` — получить записи;
- `GET /logs/stream` — SSE;
- `GET /stats` — статистика;
- `POST /clear` — очистить;
- `POST /clear-logs-by-task` — очистить по задаче.

Формат страницы определяется фактическими полями записей JSONL; документация не предполагает наличие необязательных полей.
