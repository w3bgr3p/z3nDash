# Logs

Общая история ZP7 открывается кнопкой `allLogs` на странице [[ZP7]],
ссылкой `/?page=zp7#allLogs` и хоткеем `Alt+4`.

- Все зарегистрированные узлы или выбранная машина, независимо от выбранной задачи.
- Фильтры по проекту, уровню, потоку и модулю; поиск по тексту.
- Сортировка по столбцам, полная запись и копирование сообщения.
- Execution, Errors и Critical для ZennoPoster или ProjectMaker.
- Обновление раз в 3 секунды только при открытом окне; его можно приостановить.
- Ошибки отдельных узлов отображаются рядом с результатами доступных узлов.

Данные загружаются через `GET /zp/nodes?probe=false` и `GET /zp/log`.
Текущий API возвращает до 2000 записей из последних 512 КБ файла на каждом узле.
Это доступная через API недавняя история, а не полный архив. Проект фильтруется
на узле до ограничения числа записей; остальные фильтры и сортировка применяются
к загруженным записям. У Errors и Critical нет поля проекта.

Логи читаются с узлов.
