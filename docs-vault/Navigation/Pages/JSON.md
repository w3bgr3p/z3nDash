# JSON

JSON — локальный просмотрщик и редактор JSON.

## Работа с документом

- вставка JSON;
- форматирование;
- дерево значений;
- поиск;
- сворачивание веток;
- копирование значения или пути;
- фильтрация полей.

## Security Badges

Интерфейс отмечает значения, похожие на секреты или чувствительные данные. Это эвристическая подсветка, а не проверка безопасности.

## Replay

JSON можно использовать как body при подготовке HTTP replay.

## AI-анализ

Опциональный анализ отправляется в OmniRoute. Кэш хранится в таблице `ai_json_cache`.

API:

- `POST /json-analyzer/ai-analyze`
- `GET /json-analyzer/ai-cache`
- `DELETE /json-analyzer/ai-cache`
- `GET /config/ai-models`
