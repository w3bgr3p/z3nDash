# dllGraph

dllGraph строит граф C#-кода из исходников или DLL.

На странице кнопка **Choose DLL** открывает системный диалог выбора `.dll`.
После выбора файла нажмите **Generate**.

## Вход

`POST /dllGraph/generate?repoPath=...` принимает:

- путь к одной DLL;
- каталог с DLL;
- каталог с C#-исходниками.

Каталоги `bin` и `obj` при анализе исходников исключаются.

## Результат

Сгенерированный HTML хранится в памяти процесса. `GET /dllGraph` возвращает последний построенный граф.

После перезапуска z3nDash граф нужно построить заново.

## API

- `GET /dllGraph/pick`
- `POST /dllGraph/generate`
- `GET /dllGraph`
