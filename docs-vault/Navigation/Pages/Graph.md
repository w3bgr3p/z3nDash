# Graph

Graph строит граф C#-кода из исходников или DLL.

## Вход

`POST /graph/generate?repoPath=...` принимает:

- путь к одной DLL;
- каталог с DLL;
- каталог с C#-исходниками.

Каталоги `bin` и `obj` при анализе исходников исключаются.

## Результат

Сгенерированный HTML хранится в памяти процесса. `GET /graph` возвращает последний построенный граф.

После перезапуска z3nDash граф нужно построить заново.

## API

- `POST /graph/generate`
- `GET /graph`
