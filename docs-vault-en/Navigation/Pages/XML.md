# XML

The `/xml.html` page opens arbitrary XML as a tree.

## Input

Paste XML into the editor, drop a file on the page, or choose one through the
system dialog. File encoding is detected from the BOM, including UTF-16
ZennoPoster templates. **Format** formats the source and **Parse** rebuilds the
tree.

## Tree

- search filters tags, attributes and text;
- depth presets 1, 2, 3 and 5 provide quick expansion levels;
- individual nodes or the whole tree can be expanded and collapsed;
- virtual scrolling avoids creating a DOM element for every row in a large file;
- the source/tree split can be dragged and is stored locally.

The page is available as **XML** in the dock and through `Alt+9`.
